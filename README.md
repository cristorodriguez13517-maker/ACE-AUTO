# ACE-AUTO

Actualizador automatico de listas AceStream.

## Funciones

- Descarga automatica de Elcano.
- Actualizacion cada tres horas.
- Conservacion de canales manuales.
- Deteccion de canales nuevos.
- Deteccion de canales eliminados.
- Deteccion de canales modificados.
- Historial permanente.
- Publicacion en git.gay.

## Archivos

- canales.m3u: lista automatica.
- canales_manuales.m3u: canales personales.
- historial.json: ultima version automatica.
- cambios.md: historial de modificaciones.
